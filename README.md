# COPERTO — лендинг

Одностраничный сайт ресторана и кинотеатра **COPERTO** (Москва).
Тёмный элегантный дизайн в брендовых цветах, две кнопки по центру: меню и Telegram.

---

## 📁 Состав папки

| Файл | Что это |
|------|---------|
| `index.html` | **Весь сайт в одном файле.** Стили, скрипты и логотип встроены внутрь (Base64) — никаких вложенных папок и зависимостей. |
| `QR_coperto.png` | QR-код в фирменном стиле с эмблемой COPERTO в центре. Ведёт на сайт-меню. |
| `LOGO/` | Исходные логотипы в 4 вариантах (чёрный, оливковый, белый, серо-зелёный), PNG @2x. |
| `LOGO.zip` | Те же логотипы архивом. |
| `README.md` | Этот файл. |

---

## 🚀 Как открыть

Просто дважды кликните по `index.html` — сайт откроется в браузере.
Файл самодостаточный: его можно переслать, скопировать на флешку или залить на хостинг как есть.

## 🎨 Фирменный стиль

- **Оливковый (акцент):** `#9CA13F` / тёмный `#7C8134`
- **Светло-оливковый:** `#B8BD5E`
- **Кремовый:** `#F7F6EE`
- **Тёмный фон:** `#0E0F0C` → `#15170F`
- **Логотип на сайте:** белая версия (`LOGO/Ресурс 3@2x.png`) на тёмном фоне.
- **Шрифт:** системный (`-apple-system`, `Segoe UI`) — без подгрузки внешних файлов.

## ✏️ Как отредактировать

Откройте `index.html` в любом текстовом редакторе:

- **Текст кнопок** — найдите слова `Меню` и `Telegram`.
- **Ссылки** — атрибуты `href="..."` у тегов `<a class="btn ...">`.
- **Подписи** — блоки `class="tagline"` (под логотипом) и `class="footer"` (внизу).
- **Цвета** — переменные в начале стилей (блок `:root`).
